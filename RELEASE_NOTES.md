# Master Calc v2 — альтернатива «Палитра материалов»

Отдельная версия для быстрого расчёта клиента. Базовая v2 и исходный GitHub сохранены.

- Убран переключатель «Оплата аренды»: остались тариф и часы аренды.
- Семь основных материалов показаны сразу; пустое количество означает ноль.
- Под каждой карточкой — стоимость использованного материала, под палитрой — сумма материалов.
- «Все материалы» открывает каталог с поиском. Дополнительные позиции вводятся теми же карточками.
- Enter переводит к следующему количеству; общая очистка сбрасывает материалы.
- Шаблоны, дополнительные расходы, налог и комиссия свёрнуты.
- Цена пересчитывается автоматически; одна кнопка сохранения расположена под итогом.

История, каталог, резервные копии, аналитика и офлайн-режим сохранены. Схема данных — версия 3; копии версии 2 поддерживаются. Старые чеки не пересчитываются. Повтор формирует новый чек с почасовой арендой.

Проверены 43 автоматических сценария и браузерные сценарии на четырёх ширинах, включая реальную офлайн-перезагрузку и однофайловый запуск. Полноценная облачная синхронизация не добавлялась; приём исходной Google Form не подтверждается.
