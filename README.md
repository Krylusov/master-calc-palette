# Master Calc v2.1.0 — «Палитра материалов»

Калькулятор мастера, работающего на себя. Отдельная версия из рабочей копии `master-calc`; исходный GitHub не изменён.

## Быстрый запуск

Распакуйте архив и откройте `Master_Calc_v2_Palette.html` в обычном браузере. Это самостоятельная однофайловая версия: расчёты, каталог, шаблоны, история и резервные копии не требуют сервера. Если просмотрщик файлов на телефоне не выполняет JavaScript, откройте файл именно в браузере или используйте размещённую версию.

Для полноценной PWA запустите `START_WINDOWS.bat` (нужен Python 3) или `python start_server.py`. Браузер откроется автоматически. Папку также можно разместить на HTTPS-хостинге с `index.html` как главной страницей; сборщик и сервер базы данных не нужны.

Локальный запуск использует постоянный адрес `http://127.0.0.1:8766/`, чтобы история сохранялась между запусками. При занятом порте закройте предыдущий запуск или явно задайте другой через `python start_server.py --port 8767`. При смене адреса/порта перенесите историю через JSON-копию. Однофайловая версия и PWA также имеют отдельное хранилище: переносите данные через JSON.

## Расчёт и история

Семь основных материалов доступны сразу. Избранное и порядок палитры меняются в «Настройках»; введённые количества остаются видны после снятия из избранного или архивирования материала. «Все материалы» открывает каталог, пустое количество означает ноль, Enter и Tab переходят между полями. Шаблоны и дополнительные расходы свёрнуты; подробности итоговой цены раскрываются отдельно.

Незавершённый расчёт автоматически восстанавливается в этом браузере, включая пустой и ошибочный ввод. «Новый клиент» начинает новый расчёт; успешное сохранение завершает старый черновик. Черновик не заменяет резервную копию. Время можно вводить дробными часами или часами и минутами. Если старое время содержит неполные минуты, приложение сохраняет точное значение в дробных часах. Аренду можно явно связать с длительностью работы; ручная правка аренды снимает связь.

Подсказка клиента выбирает только имя и показывает даты визитов; состав расчёта не подменяется. В «Истории» можно просмотреть чек, повторить его с текущими ценами или исправить с исходными историческими тарифами. Исправление сохраняет ID и дату, предыдущие версии доступны для восстановления. Старые чеки без полного снимка исходных тарифов доступны для просмотра и повтора, но редактировать их нельзя. Замена заполненного расчёта требует подтверждения.

При необходимости задайте фактическую цену клиента. Расчётная цена остаётся видна отдельно, а налог, комиссия и доход считаются от фактической выручки. Отрицательный доход показывается явно. Копирование цены для клиента не включает внутренние расходы и доход.

## Возможности

- Автоматический пересчёт, компоновка для телефона и компьютера, PWA с офлайн-перезагрузкой и явным обновлением.
- Работа за час или фиксированно; аренда за час. Для расчёта без аренды задайте 0 часов.
- Каталог в г/мл/шт, цена упаковки, редактирование и архивирование; шаблоны по текущим ценам.
- Несколько дополнительных расходов; пользовательские проценты налога и комиссии; удержание из дохода или включение в расчётную цену.
- Аналитика периода, поиск, история по 50 чеков, удаление с восстановлением и CSV по текущему фильтру.
- JSON-копия истории, тарифов, каталога, шаблонов, настроек палитры и удалённых чеков; предыдущие версии исправленных чеков входят в копию.

Эта версия находится в отдельной ветке и запускается на порте 8766, базовая v2 — на 8765. Исходный `master-calc` не изменяется.

## Формулы и округление

Без удержаний: цена = работа + аренда + расходники + материалы + дополнительные расходы + наценка на материалы и расходники. Доход после расходов = оплата работы + наценка.

Налог и комиссия рассчитываются по указанным пользователем процентам от итоговой цены. По умолчанию оба процента равны нулю. Если их включение в цену выключено, удержания уменьшают доход; если включено, цена увеличивается, чтобы покрыть их. Сумма процентов должна быть меньше 100%.

Деньги рассчитываются в целых копейках. Каждая строка материала, работы, аренды и расхода округляется до копеек; наценка и удержания округляются отдельно. При включении удержаний в цену применяется округление вверх с проверкой покрытия. Просмотр старых чеков не пересчитывает их и не добавляет выдуманные исторические тарифы. Исправление доступно только при наличии полного исторического снимка.

## Сохранение и перенос

История, тарифы, каталог, шаблоны и черновик хранятся локально в браузере. Регулярно скачивайте JSON-копию в «Настройках» и проверяйте файл в загрузках: очистка данных браузера может удалить записи без возможности восстановления. Для переноса импортируйте копию на новом адресе/в новом браузере. Напоминание показывает изменения чеков после последнего скачивания; оно не подтверждает сохранность файла.

Копия версии 3 включает историю, тарифы, каталог, шаблоны и удалённые чеки. Импорт объединяет историю по ID (текущая запись имеет приоритет), после подтверждения заменяет тарифы, каталог и шаблоны. Копия версии 2 поддерживается и оставляет текущие каталог и шаблоны. Исходное состояние перед импортом сохраняется. Некорректные файлы отклоняются.

В «Настройках» можно явно отключить попытку отправки новых чеков в исходную Google Form проекта. Прежнее значение по умолчанию сохранено: отправка включена, пока её не отключили. Приём формы не подтверждается приложением. Без сети чек сохраняется только локально; автоматического повторного отправления нет. Исправление и восстановление версии чека не отправляются. Облачной синхронизации, чтения истории и облачного удаления нет. Удаление/восстановление меняет только локальную историю; Google Forms не является резервной копией.

## Разработка и проверки

`node --test tests/*.test.cjs` — 108 проверок без внешних зависимостей.

`tests/browser-check.cjs` — интеграционная проверка в Chromium/Playwright. Укажите установленные зависимости через `QA_PLAYWRIGHT` и `QA_CHROMIUM` либо JSON-файл `QA_LAUNCH_CONFIG` с `executablePath` и `args`. Проверка запускает временный локальный сервер, проверяет исходники и однофайловую сборку, блокирует все внешние запросы. Отдельные сценарии: `tests/palette-browser-check.cjs` и `tests/history-browser-check.cjs`.

`python scripts/build_release.py` — сборка однофайловой версии и ZIP из исходников. Подробности проверки — в `QA_REPORT.md`, автономный отчёт с раскрывающимися блоками — `qa/Master_Calc_v2.1_Audit.html`, текстовые доказательства — в `qa/`, история доработок — в `ROADMAP_V2.md`.

Для GitHub Pages хранилище и кэш «Палитры» изолированы от первого сайта на том же домене. История первого сайта автоматически не переносится; используйте JSON-копию.
