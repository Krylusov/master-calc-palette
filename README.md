# Master Calc v2 — «Палитра материалов»

Калькулятор мастера, работающего на себя. Отдельная версия из рабочей копии `master-calc`; исходный GitHub не изменён.

## Быстрый запуск

Распакуйте архив и откройте `Master_Calc_v2_Palette.html` в обычном браузере. Это самостоятельная однофайловая версия: расчёты, каталог, шаблоны, история и резервные копии не требуют сервера. Если просмотрщик файлов на телефоне не выполняет JavaScript, откройте файл именно в браузере или используйте размещённую версию.

Для полноценной PWA запустите `START_WINDOWS.bat` (нужен Python 3) или `python start_server.py`. Браузер откроется автоматически. Папку также можно разместить на HTTPS-хостинге с `index.html` как главной страницей; сборщик и сервер базы данных не нужны.

Локальный запуск использует постоянный адрес `http://127.0.0.1:8766/`, чтобы история сохранялась между запусками. При занятом порте закройте предыдущий запуск или явно задайте другой через `python start_server.py --port 8767`. При смене адреса/порта перенесите историю через JSON-копию. Однофайловая версия и PWA также имеют отдельное хранилище: переносите данные через JSON.

## Альтернативный интерфейс

Семь основных материалов доступны в палитре без добавления строк. Введите количество: пустое поле означает ноль. Цена материалов и итог меняются автоматически. Enter и Tab переводят к следующему полю. «Все материалы» открывает поиск по активному каталогу; дополнительные материалы появляются в палитре. «Очистить количества» сбрасывает только материалы.

Шаблоны услуг и дополнительные расходы свёрнуты. Под итогом одна кнопка «Сохранить чек». Переключатель «Оплата аренды» убран. Сохранённые чеки остаются неизменными; повтор старого чека создаёт новый расчёт с почасовой арендой по текущим тарифам.

Эта версия находится в отдельной ветке и запускается на порте 8766, базовая v2 — на 8765. Для сравнения не импортируйте данные без необходимости; для переноса используйте JSON-копию.

## Возможности

- Автоматический пересчёт; компоновка для телефона и компьютера.
- Работа за час или фиксированно. Аренда за час: тариф и количество часов; для расчёта без аренды задайте 0 часов.
- Каталог: г, мл, шт, цена упаковки, редактирование и архивирование.
- Шаблоны услуг без имени клиента; материалы и часовые ставки — по текущим ценам.
- Несколько дополнительных расходов, пользовательские проценты налога и комиссии от итоговой выручки.
- Выбор: вычитать удержания из дохода или включать их в цену клиента.
- Аналитика периода, поиск, история по 50 чеков, удаление с восстановлением.
- CSV за выбранный период и по текущему поиску; JSON-копия всех данных.
- PWA: предварительное кэширование, офлайн-перезагрузка, явное обновление приложения.

## Формулы и округление

Без удержаний: цена = работа + аренда + расходники + материалы + дополнительные расходы + наценка на материалы и расходники. Доход после расходов = оплата работы + наценка.

Налог и комиссия рассчитываются по указанным пользователем процентам от итоговой цены. По умолчанию оба процента равны нулю. Если их включение в цену выключено, удержания уменьшают доход; если включено, цена увеличивается, чтобы покрыть их. Сумма процентов должна быть меньше 100%.

Деньги рассчитываются в целых копейках. Каждая строка материала, работы, аренды и расхода округляется до копеек; наценка и удержания округляются отдельно. При включении удержаний в цену применяется округление вверх с проверкой покрытия. Сохранённые старые чеки не пересчитываются и не получают выдуманные исторические тарифы.

## Сохранение и перенос

История, тарифы, каталог и шаблоны хранятся в браузере. Очистка данных браузера или смена адреса не переносит историю. Для переноса скачайте JSON-копию в разделе «База» и импортируйте её в новом адресе/браузере.

Копия версии 3 включает историю, тарифы, каталог, шаблоны и удалённые чеки. Импорт объединяет историю по ID (текущая запись имеет приоритет), после подтверждения заменяет тарифы, каталог и шаблоны. Копия версии 2 поддерживается и оставляет текущие каталог и шаблоны. Исходное состояние перед импортом сохраняется. Некорректные файлы отклоняются.

Сохранение при доступной сети также инициирует отправку в исходную Google Form проекта. Приём этой формы не подтверждается приложением. Без сети чек сохраняется только локально; автоматического повторного отправления нет. Синхронизация, чтение облачной истории и облачное удаление не реализованы. Удаление/восстановление в приложении меняет только локальную историю.

## Разработка и проверки

`node --test tests/*.test.cjs` — 43 проверки без внешних зависимостей.

`tests/browser-check.cjs` — интеграционная проверка в Chromium/Playwright. Укажите установленные зависимости через `QA_PLAYWRIGHT` и `QA_CHROMIUM`. Проверка запускает временный локальный сервер и блокирует отправку в Google Forms.

`python scripts/build_release.py` — сборка однофайловой версии и ZIP из исходников. Подробности проверки — в `QA_REPORT.md`, история доработок — в `ROADMAP_V2.md`.

Для GitHub Pages хранилище и кэш «Палитры» изолированы от первого сайта на том же домене. История первого сайта автоматически не переносится; используйте JSON-копию.
